# AI 逻辑审查（AI Logic Reviewer）

基于 DeepSeek 大模型的代码逻辑审查工具，直接在 VS Code 里对代码做「AI 预检」，重点发现人眼容易漏掉的逻辑缺陷。

适合在**提交代码前自测**、**Code Review 前预检**、**接手陌生代码时快速摸底**。

---

## 一、它能查什么

- 死循环 / 递归无终止条件
- Promise 未捕获、`async/await` 误用
- React `useEffect` 依赖错误导致的无限渲染
- 内存泄漏（timer / event listener 未清理）
- 空值 / undefined 导致的运行时崩溃
- 闭包捕获过期变量
- 异步竞态、资源未释放、异常吞掉

输出为中文报告，按 **高 / 中 / 低** 分级，每条给出**文件位置 + 原因 + 修复建议**。

> 注意：这是逻辑层面的辅助审查，**不能替代** ESLint / 单元测试 / 人工 Review。

---

## 二、安装

### 方式一：从 VSIX 安装（推荐）

1. 打开 VS Code，按 `Ctrl+Shift+X` 打开扩展面板
2. 点右上角 `...` → **Install from VSIX...**
3. 选择收到的 `ai-logic-reviewer-x.x.x.vsix`
4. 弹出信任提示时点 **Trust**
5. **重启 VS Code**（或 `Ctrl+Shift+P` → `Developer: Reload Window`）

### 方式二：命令行安装

```bash
code --install-extension ai-logic-reviewer-x.x.x.vsix
```

> 用的是 VS Code Insiders 就把 `code` 换成 `code-insiders`。

### 环境要求

- VS Code **1.85.0** 及以上
- 可访问 `https://api.deepseek.com`（公司网络需放行）

---

## 三、配置 API Key（首次必做）

1. `Ctrl+Shift+P` 打开命令面板
2. 输入并执行：**`AI 审查：设置 DeepSeek Key`**
3. 粘贴你的 Key（格式 `sk-xxxxxxxx`），回车

### 获取 Key

1. 访问 <https://platform.deepseek.com/>
2. 登录 → 左侧「API Keys」→ **创建 API Key**
3. 复制保存（**只显示一次**，关掉就看不到了）

### Key 存在哪

存于 VS Code 的 `SecretStorage`，底层调用操作系统密钥库（Windows 凭据管理器 / macOS Keychain / Linux Secret Service），**不写入任何配置文件，不上传到第三方**。每台机器各自独立。

修改 Key：再执行一次「设置 DeepSeek Key」覆盖即可。

## 四、怎么用

### 三个审查范围

| 命令 | 扫描范围 | 适用场景 |
|---|---|---|
| **AI 审查：当前文件** | 当前打开的文件 | 改完一个文件，快速自检 |
| **AI 审查：当前包** | 当前文件所在目录（含子目录） | 改完一个模块，检查整体 |
| **AI 审查：整个项目** | 整个工作区所有源码 | 接手项目摸底 / 上线前兜底 |

### 三种触发方式

**1. 编辑器右键**

在代码编辑区右键 → 菜单顶部选：

- `AI 审查：当前文件`
- `AI 审查：当前包`

**2. 资源管理器右键**

在左侧文件树里右键**文件夹** → 选：

- `AI 审查：当前包`（审这个目录）
- `AI 审查：整个项目`

**3. 命令面板**

`Ctrl+Shift+P` → 输入 `AI 审查` → 选择对应命令。

### 查看结果

审查期间右下角显示进度条，完成后在**侧边**打开「AI 逻辑审查报告」面板。

## 五、扫描规则（重要）

为了控制 token 消耗和响应速度，扫描时有以下限制：

**会扫描的文件类型**

`.ts` `.tsx` `.js` `.jsx` `.mjs` `.cjs` `.vue` `.svelte` `.html` `.css` `.scss` `.less` `.json` `.java` `.kt` `.py` `.go` `.rs` `.sql` `.yml` `.yaml` `.xml`

**会自动跳过的目录**

`node_modules` `dist` `build` `out` `coverage` `target` `vendor` `__pycache__` `.git` `.idea` `.vscode` `.next` `.nuxt` 以及所有以 `.` 开头的目录

**容量上限**

| 限制项 | 上限 |
|---|---|
| 文件数量 | 300 个 |
| 累计字符 | 约 200,000 |
| 单文件字符 | 约 60,000（超出截断） |

超出上限时，报告头部会标注「已达上限，后续文件被截断」，说明模型只分析了部分代码。**审整个项目时建议缩小到具体模块再跑一次**，结果会更准。

## 六、常见问题

**Q：右键菜单里找不到「AI 审查」？**
A：先确认扩展已启用（`Ctrl+Shift+X` 搜索 `AI 逻辑审查`），再 `Developer: Reload Window` 重载窗口。若仍没有，检查文件是否在受信任的工作区（左下角是否显示「受限模式」）。

**Q：提示「审查失败：HTTP 401」？**
A：Key 无效或已过期。重新执行「设置 DeepSeek Key」覆盖。

**Q：提示「审查失败：HTTP 402」？**
A：DeepSeek 账户余额不足，去平台充值。

**Q：提示「审查失败：HTTP 429」？**
A：请求过于频繁，等几十秒再试。

**Q：提示「没有可审查的代码」？**
A：当前目录下没有符合白名单的源码文件，或全部被跳过规则排除了。

**Q：一直转圈没结果？**
A：整个项目代码量大时，模型推理需要 30 秒以上，属正常。若超过 2 分钟无响应，检查网络是否能访问 `api.deepseek.com`。

**Q：审查结果没查出我预期的问题？**
A：① 确认问题代码在扫描范围内（没被截断、没被跳过）；② 用「当前文件」单独审一次，范围越小越准；③ 逻辑类问题本身有主观性，模型可能漏判，重要代码仍需人工 Review。

## 七、更新

VSIX 安装的扩展**不会自动更新**。收到新版 vsix 后：

1. `Ctrl+Shift+X` → 找到 `AI 逻辑审查` → 齿轮图标 → **卸载**
2. 重新 **Install from VSIX...** 安装新版
3. 重启 VS Code

API Key 会保留，无需重新配置。
